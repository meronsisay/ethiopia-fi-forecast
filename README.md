# Ethiopia Financial Inclusion — Forecasting System

Forecasting Ethiopia's Access (account ownership) and Usage (digital payment adoption)
using a unified events/observations/impact-link dataset, per the Global Findex framework.

## Project Structure

```
ethiopia-fi-forecast/
├── .github/workflows/unittests.yml   # CI: runs pytest on every push/PR
├── data/
│   ├── raw/                          # Starter + enriched dataset (do not overwrite in place)
│   └── processed/                    # Cleaned, analysis-ready data (generated by src/ scripts)
├── notebooks/                        # Exploration, EDA, modeling notebooks (one per task)
├── src/                              # Reusable python modules (loading, cleaning, modeling)
├── dashboard/app.py                  # Streamlit dashboard
├── tests/                            # Unit tests
├── models/                           # Saved model artifacts (gitignored, regenerable)
├── reports/figures/                  # Exported charts for the write-up
├── requirements.txt

```

## Data

- `data/raw/ethiopia_fi_unified_data.csv` — unified schema: `observation`, `event`, `impact_link`,
  and `target` records all in one table. See root-level schema notes below.
- `data/raw/reference_codes.csv` — valid values for every categorical field.
- `data/raw/Additional_Data_Points_Guide.xlsx` — supplementary sheet of candidate enrichment sources
  (alternative baselines, direct/indirect correlation indicators, Ethiopia market nuances).

### Schema at a glance

| record_type   | `category` filled? | `pillar` filled? | What it represents |
|---------------|---------------------|-------------------|---------------------|
| `observation` | no                  | yes               | A measured value (survey/operator/infra data) |
| `event`       | yes                 | **no** (never pre-assigned) | A policy/launch/milestone |
| `impact_link` | no                  | yes               | Modeled effect of an event (via `parent_id`) on an indicator |
| `target`      | no                  | yes               | An official policy goal |


## Setup (Python 3.11)

```bash
# 1. Clone
git clone https://github.com/<your-username>/ethiopia-fi-forecast.git
cd ethiopia-fi-forecast

# 2. Create & activate a virtual environment (python3.11 required)
python3.11 -m venv venv
source venv/bin/activate        # macOS/Linux
# venv\Scripts\activate         # Windows

# 3. Install dependencies
pip install --upgrade pip
pip install -r requirements.txt

```
